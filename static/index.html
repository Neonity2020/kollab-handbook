常见问题

你可能想问的

Kollab 和 ChatGPT 有什么区别？▼
ChatGPT 是对话 AI，Kollab 是能实际执行任务的 AI Agent 平台。Kollab 可以真实地写代码并部署、读取你的 GitHub 仓库、处理你上传的文件、联网搜索——而不只是给你文字回答。
生成的文件在哪里下载？▼
Kollab 会把所有用户面向的文件上传到 S3，并在对话中给你一个下载链接。链接有效期 24 小时，文件会在平台内持久保存。点击链接直接下载即可。
部署的应用能用多久？▼
Elastic Beanstalk 环境是临时的，约 24 小时后会被清理。但 Kollab 会同时给你源码的 ZIP 下载链接，你可以随时重新部署到自己的服务器或继续在 Kollab 里重新部署。
我的数据安全吗？▼
上传的文件存储在隔离的工作区，每个对话有独立的 S3 空间。Kollab 不会把你的文件用于模型训练，也不会在不同用户之间共享数据。GitHub 等集成通过 OAuth 授权，你可以随时撤销。
如何连接 GitHub/Notion 等外部工具？▼
在 Kollab 工作区的「MCP 服务器」设置里，可以添加 GitHub、Notion、飞书、企业微信等连接器。连接后在对话中直接说「读取我的 GitHub 仓库 XXX」即可操作。
可以让 AI 记住我的偏好吗？▼
可以，直接说「记住我的 XXX 偏好」或「以后都用 XXX 风格」，AI 会把它存入持久化的工作区记忆（MEMORY.md），跨会话生效。
