# 快速入门

欢迎！这一节会带你在 5 分钟内完成 Kollab 的基本配置，并开始你的第一个 AI 对话。

## 第一步：注册账号

1. 访问 [kollab.cc](https://kollab.cc) 并点击「免费注册」
2. 使用邮箱或微信扫码登录
3. 完成个人资料设置

## 第二步：创建第一个空间

**空间（Space）** 是 Kollab 的基本组织单元，类似于一个项目文件夹。

```
空间 > 项目 > 任务 / 对话 / 文档
```

点击左侧边栏的 **「+ 新建空间」**，输入名称，选择图标，完成创建。

<Callout type="tip">
  建议按照项目或团队来划分空间。例如：「产品研发」「市场营销」「个人助手」各一个空间。
</Callout>

## 第三步：发起第一个 AI 对话

1. 进入你创建的空间
2. 点击 **「新建对话」**
3. 在输入框输入你的第一个问题，按回车发送

就这么简单！AI 会立即回复，你可以继续追问、要求修改、或者开始新话题。

## 第四步：上传文档（可选）

想让 AI 了解你的业务？上传你的内部文档：

1. 进入「知识库」选项卡
2. 点击「上传文件」，支持 PDF、Word、TXT、Markdown
3. 等待处理完成（通常几秒到几分钟）
4. 在对话中 @知识库 即可让 AI 参考你的文档
