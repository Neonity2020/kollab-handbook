# 团队协作设置

Kollab 支持从个人使用到百人团队的灵活扩展。这一节介绍如何配置一个高效的团队工作空间。

## 邀请团队成员

### 方式一：邀请链接

1. 进入空间「设置」→「成员管理」
2. 点击「生成邀请链接」
3. 将链接分享给团队成员，他们访问链接后即可加入

### 方式二：邮件邀请

1. 同样在「成员管理」页面
2. 输入成员邮箱，选择角色
3. 点击「发送邀请」

## 角色与权限

| 角色 | 权限描述 |
|------|----------|
| **Owner** | 空间所有者，拥有全部权限 |
| **Admin** | 可管理成员和配置，不可转让所有权 |
| **Editor** | 可创建和编辑内容，不可管理成员 |
| **Viewer** | 只读权限，适合外部查阅 |

<Callout type="info">
  权限是空间级别的。同一个人在不同空间可以有不同角色。
</Callout>

## 共享知识库

团队空间中的知识库对所有有权限的成员共享。上传一次，全员受益。

推荐的知识库结构：

```
📂 产品文档
  ├── PRD v2.0.pdf
  └── 竞品分析.docx
📂 内部规范
  ├── 代码规范.md
  └── 设计规范.pdf
📂 会议纪要
  └── 2026-Q1 规划会.txt
```

## 最佳实践

1. **用空间隔离项目**，不要把所有内容堆在一个空间里
2. **定期清理知识库**，过时文档会让 AI 产生混淆
3. **给 AI 取个名字**，让团队成员更容易记住如何 @ 它
