# 知识库

知识库是 Kollab 最核心的功能之一。它让 AI 从「通用助手」变成「了解你业务的专家」。

## 支持的文件格式

| 格式 | 说明 |
|------|------|
| PDF | 最常用，支持图文混排 |
| Word (.docx) | Office 文档 |
| Markdown (.md) | 技术文档首选 |
| TXT | 纯文本，处理最快 |
| Excel (.xlsx) | 表格数据 |
| 网页链接 | 自动抓取网页内容 |

<Callout type="info">
  单个文件大小限制为 50MB。如有更大文件，建议先拆分后再上传。
</Callout>

## 上传流程

1. 进入「知识库」选项卡
2. 点击「+ 上传」或直接拖拽文件
3. 等待 AI 处理文档（状态会从「处理中」变为「就绪」）
4. 完成！在对话中这个知识库就可以被引用了

## 知识检索原理

Kollab 使用 **向量检索（Vector Search）** 技术：

```
你的问题
   ↓  (转化为向量)
相似度计算
   ↓  (找出最相关片段)
召回 Top-K 内容
   ↓  (送给 AI 参考)
AI 综合回答
```

这比传统的关键词搜索更准确——即使你的措辞和文档里不一样，也能找到正确答案。

## 最佳实践

### 文档质量很重要

- 清晰的标题和章节结构 → 检索更准确
- 去掉无关的页眉页脚 → 减少噪音
- 保持文档更新 → 避免 AI 给出过时信息

### 合理组织知识库

建议按主题分类，而不是把所有文档堆在一个知识库里：

```
📂 产品手册（公开）
📂 内部规范（团队）
📂 竞品情报（私密）
```
