# 检索优化

知识库配置好了，但 AI 的回答还不够准确？这里有一些实用技巧。

## 调整检索参数

### 召回数量（Top-K）

每次检索时返回多少个相关片段。

- **太少（1-2）**：信息不完整，AI 可能漏掉关键内容
- **太多（10+）**：噪音增加，AI 容易混淆
- **推荐值（3-6）**：大多数场景的最佳平衡点

### 相似度阈值

控制「够像才召回」的标准，范围 0-1。

```
低阈值（0.5）→ 召回更多，但可能包含不相关内容
高阈值（0.9）→ 召回更精准，但可能漏掉有用内容
推荐：0.7 - 0.8
```

## 优化文档本身

好的文档结构让检索效果成倍提升：

### ✅ 推荐做法

```markdown
# 退款政策

## 退款条件
用户在购买后 7 天内可申请退款，需满足以下条件：
1. 产品未被激活
2. 未超过使用次数限制

## 退款流程
1. 联系客服提交退款申请
2. 审核周期为 1-3 个工作日
```

### ❌ 避免这样写

```
退款：7天，未激活，联系客服，1-3天审核
```

结构化的文档，每个段落聚焦一个主题，检索效果远优于压缩的纯信息堆砌。

## 使用文档摘要

在上传时为每个文档添加「摘要」字段：

> 「这是 2026 年 Q1 的退款政策文档，适用于所有付费用户」

AI 会先读摘要判断文档是否相关，再决定是否深入检索内容，大幅提升精准度。

## 常见问题排查

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| AI 回答与文档不符 | 文档版本过旧 | 更新文档 |
| 明明有相关内容但 AI 找不到 | 阈值过高 | 降低相似度阈值 |
| AI 混淆了不同文档的内容 | 文档主题重叠 | 拆分知识库，分类管理 |
| 检索速度慢 | 知识库过大 | 清理冗余文档 |
