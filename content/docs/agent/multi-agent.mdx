# 多智能体协作

单个智能体擅长通用任务，但面对复杂的多步骤工作流，**多个专业化智能体分工合作**才是正解。

## 为什么需要多智能体

想象一个完整的内容生产流程：

```
情报官 (Research Agent)
  → 收集市场信息、竞品动态

内容官 (Content Agent)
  → 基于情报撰写文章

审稿官 (Review Agent)
  → 检查事实、优化措辞

发布官 (Publisher Agent)
  → 格式化并推送到各渠道
```

每个智能体专注自己的领域，质量比单一通用智能体高出很多。

## 设置主智能体（Leader）

在多智能体架构中，通常需要一个「协调者」角色：

**系统提示词模板：**

```
你是团队的 Leader，负责统筹协调。

当收到任务时：
1. 分析任务性质，决定分配给哪个专家
2. @情报官 负责信息收集
3. @内容官 负责内容创作
4. 汇总结果，向用户汇报

你只负责调度，不直接执行具体任务。
```

## 智能体间通信

在 Kollab 中，智能体可以通过 **@提及** 互相调用：

1. 在对话中输入 `@智能体名称`
2. 附上你的指令或上一步的结果
3. 被 @ 的智能体会接管并完成任务

<Callout type="tip">
  给每个智能体取一个简短易记的名字，方便 @ 调用。例如：研究员、写手、校对。
</Callout>

## 实战案例：市场调研流程

**第一步**：让情报官收集信息
```
@研究员 请调研 2026 年 AI 协作工具市场的最新动态，
重点关注：市场规模、主要玩家、用户痛点
```

**第二步**：让内容官写报告
```
@写手 基于以下调研结果，写一份 800 字的市场分析报告：
[粘贴研究员的输出]
```

**第三步**：让审稿官优化
```
@校对 请检查这份报告的准确性和可读性，
如有数据引用请确认来源，语言风格保持专业但易读
```
