# AI 智能体

Kollab 的智能体（Agent）不只是一个聊天机器人。你可以给它设定角色、连接知识库、赋予工具能力，让它成为你团队里最高效的协作伙伴。

## 什么是智能体

智能体 = **模型** + **身份设定** + **知识** + **工具**

```
┌─────────────────────────────────────┐
│           你的智能体                 │
├─────────────┬───────────────────────┤
│  底层模型   │  Claude / GPT / Gemini │
│  身份设定   │  角色、语气、专长      │
│  知识库     │  你上传的文档          │
│  工具       │  搜索、代码执行等      │
└─────────────┴───────────────────────┘
```

## 创建智能体

1. 在空间内点击「智能体」→「新建智能体」
2. 填写基本信息：
   - **名称**：给它取个好记的名字
   - **头像**：选个合适的 emoji 或上传图片
   - **描述**：一句话说明它的用途

3. 配置系统提示词（见下节）

## 配置系统提示词

系统提示词决定了智能体的「性格」和「边界」。写得越具体，表现越稳定。

**模板：**

```
你是 [角色名称]，[公司名] 的 [职位/职能]。

你的主要职责：
1. [职责 1]
2. [职责 2]

回答风格：简洁、专业、中文优先。
如果不确定，请如实告知而不是编造。
```

<Callout type="tip">
  好的系统提示词通常在 200-500 字之间。太短没有约束力，太长模型容易遗忘后半段。
</Callout>

## 绑定知识库

在智能体配置页面，切换到「知识」选项卡，勾选你希望它参考的知识库。

智能体在回答时会自动检索相关内容，并在回复中标注来源。
