# 智能体配置详解

## 基础配置

### 模型选择

Kollab 支持接入多种主流模型：

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| Claude Opus | 推理能力强，思考深度高 | 复杂分析、代码评审 |
| Claude Sonnet | 速度与质量平衡 | 日常助手、文案创作 |
| GPT-4o | 多模态支持好 | 图片分析、视觉任务 |
| Gemini Pro | Google 生态集成 | 搜索增强、长文档 |

### 温度（Temperature）

控制回复的随机性，范围 0-1：

- **0.0**：几乎固定，适合数据提取、代码生成
- **0.3-0.5**：均衡，适合大多数对话场景
- **0.8-1.0**：富有创意，适合头脑风暴、创意写作

## 上下文设置

### 记忆长度

设置智能体能「记住」多少轮对话历史。

- 短记忆（8轮）：节省 Token，适合一问一答
- 长记忆（32轮）：保持连贯性，适合复杂项目讨论

### 知识库检索

| 设置项 | 说明 |
|--------|------|
| 检索数量 | 每次召回多少条知识片段（建议 3-8 条） |
| 相似度阈值 | 控制检索精度（0.7-0.85 通常效果较好） |
| 引用显示 | 是否在回复中显示知识来源 |

## 高级设置

### 工具调用

为智能体开启外部工具能力：

- **网络搜索**：实时获取最新信息
- **代码执行**：运行 Python/JavaScript
- **文件处理**：读写工作空间文件
- **API 调用**：连接你的内部系统

<Callout type="warning">
  工具调用会消耗更多 Token 和响应时间。只开启你真正需要的工具。
</Callout>

### 响应格式

可以强制智能体按特定格式输出：

```
回复必须按以下 JSON 格式输出：
{
  "summary": "一句话总结",
  "details": "详细内容",
  "action_items": ["行动项1", "行动项2"]
}
```
