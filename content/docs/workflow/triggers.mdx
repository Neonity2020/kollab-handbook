# 触发器详解

触发器决定了工作流「什么时候」启动。Kollab 支持以下触发类型：

## 定时触发

最简单的触发方式，按照你设定的时间表定期执行。

### Cron 表达式

```
┌──── 分钟 (0-59)
│  ┌──── 小时 (0-23)
│  │  ┌──── 日 (1-31)
│  │  │  ┌──── 月 (1-12)
│  │  │  │  ┌──── 星期 (0-7, 0和7均为周日)
│  │  │  │  │
*  *  *  *  *
```

**常用示例：**

| 表达式 | 含义 |
|--------|------|
| `0 8 * * 1-5` | 周一到周五早上 8 点 |
| `0 9 * * *` | 每天早上 9 点 |
| `*/30 * * * *` | 每 30 分钟 |
| `0 0 1 * *` | 每月 1 号零点 |

<Callout type="tip">
  如果不熟悉 Cron 语法，可以用 Kollab 内置的可视化时间选择器，自动生成表达式。
</Callout>

## 事件触发

当特定事件发生时启动工作流。

### 对话事件

| 事件 | 说明 |
|------|------|
| `message.received` | 用户发送消息时 |
| `conversation.started` | 新对话开始时 |
| `conversation.ended` | 对话结束时 |

### 文件事件

| 事件 | 说明 |
|------|------|
| `file.uploaded` | 有文件上传到知识库时 |
| `knowledge.updated` | 知识库内容更新时 |

### 任务事件

| 事件 | 说明 |
|------|------|
| `task.created` | 新任务创建时 |
| `task.completed` | 任务完成时 |
| `task.overdue` | 任务超期时 |

## Webhook 触发

外部系统向 Kollab 发送 HTTP 请求时触发。

每个工作流都有唯一的 Webhook URL：
```
https://kollab.cc/webhook/wf_xxxxxxxx
```

支持验证签名，确保请求来自可信来源。

## 手动触发

点击按钮立即执行，适合：
- 测试工作流
- 临时一次性任务
- 需要人工确认后再执行的场景
