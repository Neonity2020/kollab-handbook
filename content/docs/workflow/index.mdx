# 工作流

工作流（Workflow）是 Kollab 的自动化引擎。你可以设定触发条件和执行步骤，让平台在合适的时机自动完成任务——无需人工干预。

## 核心概念

```
触发器 (Trigger)
  → 什么情况下启动
  → 例如：定时、有人提问、文件上传

动作 (Action)
  → 执行什么
  → 例如：调用 AI、发送通知、更新数据

条件 (Condition)
  → 满足什么条件才继续
  → 例如：如果置信度 > 80%
```

## 常见工作流场景

### 每日简报自动化

每天早上 8 点，自动：
1. 抓取昨日的重要消息（新闻、Slack、邮件）
2. 让 AI 总结为 200 字简报
3. 推送到企业微信群

### 客服自动响应

当用户在对话中提问时，自动：
1. 在知识库中搜索相关答案
2. 如果置信度 > 85%，直接回复
3. 如果置信度低，转交人工客服并附上参考内容

### 内容生产流水线

当你上传一篇原始稿件时，自动：
1. 情报官提取关键信息
2. 内容官重写为目标风格
3. 校对官检查并优化
4. 完成后通知你审核

## 创建第一个工作流

1. 在空间内点击「工作流」→「新建」
2. 选择触发方式（定时 / 事件触发）
3. 添加动作步骤
4. 测试运行
5. 启用
